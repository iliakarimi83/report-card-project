# report-card-project
It's been two months i have started programming and it's my first exercise project. i created this on the 40th day.
It makes report cards in excel files, you can create report cards for a whole class or a single report card.
app.py is to make a single report card and it will save in a folder called other in report-card folder.
main.py is to make report cards for a whole class and it will save them in a folder you set for the class.
